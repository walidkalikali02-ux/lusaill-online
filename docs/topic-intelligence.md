# محرك ذكاء الموضوعات — الإصدار الأول

## الغرض والنطاق
مسار خاص بالمدير في `/admin/intelligence`: إنشاء مشروع بموضوع ودولة، استيراد روابط، وضعها في طابور دائم، تشغيل الجلب، طلب التحليل، مراجعة الخريطة والفجوات والفرص، ثم اعتماد خطة التنفيذ أو رفضها مع سبب. الاعتماد هنا للتخطيط، ولا ينشر أو يدمج أو يحذف أي مقال. المقالات العامة وتواريخ مراجعتها لا تتغير.

## البنية
Next.js 16 وTypeScript وSupabase الحالية. ثمانية جداول مترابطة `ti_projects/sources/jobs/snapshots/analyses/opportunities/decisions/agent_runs` تعيد استخدام `cms_admins` و`cms_publications` و`cms_reports`. جميع الجداول محمية بـRLS، ولا يملك الزائر أو المستخدم غير المدير صلاحية الاطلاع. وظائف الحجز والحفظ المميزة داخل `ti_private`، مع واجهات invoker محدودة. مفتاح العامل مخزن كبصمة SHA256 فقط. لا يوجد مفتاح خدمة في المتصفح.

صفحات الواجهة تعرض نظرة عامة، المصادر، الخريطة، المقارنة، الفجوات، فرص المحتوى، الأدوات، المستندات، الاعتماد، الجودة، الأداء، المهام والأدلة. هي مشاهد لبيانات المشروع المحفوظة وليست نتائج توضيحية مصطنعة. البيانات مرقمة بصفحات API من 100 سجل، وبحد 100 مشروع في القائمة. تقارير البحث مقتبسة من الاستيرادات الموجودة؛ لا يوجد اتصال Search Console API حي.

## الاستيراد والزحف
روابط منفردة ودفعات حتى50 رابطًا في الطلب، TXT/CSV وXLSX حتى2MB. XLSX يقرأ خلايا روابط الورقة الأولى فقط؛ لا ينفذ صيغًا أو وحدات ماكرو، ويرفض العلاقات الخارجية والأرشيفات غير الآمنة. لا يقرأ روابط hyperlink الخارجية؛ يلزم وضع URL كنص في الخلية أو تصديره CSV. خريطة الموقع حتى4 ملفات و50 عنوانًا من نفس المضيف. لا يوجد استكشاف تلقائي لكل الدومين.

HTTPS فقط دون بيانات دخول أو منافذ مخصصة. DNS عام مثبت للاتصال، وإعادة تحقق عند التوجيهات، حتى3 تحويلات، وحدود استجابة2MB ووقت15 ثانية للاتصال. robots له أولوية، والفشل في قراءته يمنع الجلب باستثناء404/410. لا تجاوز للمصادقة أو جدران الدفع أو CAPTCHA. المحتوى المحمّل بجافاسكريبت وحده قد يتوقف صراحة. الاستخراج يحفظ العناوين والأقسام والجداول والقوائم والروابط والصور والبيانات المنظمة والمؤلفين والتواريخ المرصودة والبصمة. هو دليل لما قاله المصدر، وليس تصديقًا لادعاءاته.

## العامل والتحليل
حجز ذري مع SKIP LOCKED وlease خمس دقائق،3 محاولات بحد أقصى، تراجع زمني، إلغاء آمن، واستعادة الحجز المنتهي. يمنع تزامن جلب المضيف نفسه بين العمليات وتوجد مهلة قصيرة بين المحاولات. سجل الحالة والأخطاء دائم. `run` ينفذ مهمة واحدة من المشروع المختار، وليس كل المشاريع. المحاولات المحجوبة لا تُعرض كنجاح.

تعريفات14 دورًا ومهامها واعتمادياتها في `lib/intelligence/agents.ts`. في هذا الإصدار، الجلب والتحقق البنيوي حتميان، والأدوار الدلالية تنفذ كمهمة نموذج مجمعة واحدة، ويُسجّل ذلك بوضوح؛ لم تُنشأ14 استدعاءً مستقلًا للنموذج. لا توجد حلقة وكلاء مفتوحة أو أدوات تنفيذ أو نشر يملكها النموذج. التحقق من الادعاءات واعتماد النشر بوابتان بشريتان.

التحليل يستخدم12 مصدرًا كحد أقصى، وحتى100000 حرف من أقسامها، مع فهرس جميع مقالات لوسيل المنشورة ومقتطفات محدودة منها. النص المقتطع موسوم جزئيًا، والصفحات غير المجلوبة مسجلة. التحليل لا يمثل مسحًا كاملًا للسوق ولا تدقيقًا كاملًا لكل مقال لوسيل. JSON يخضع لـZod ثم فحص المراجع والاقتباسات وروابط لوسيل والعلاقات. كل ادعاء غير متحقق افتراضيًا. المخرجات والتفسيرات بالعربية، والقيم التقنية تبقى معرفات.

## الذكاء الاصطناعي والتكلفة
`AI_GATEWAY_MODEL` معرّف من قائمة AI Gateway الحية. المصادقة `AI_GATEWAY_API_KEY` أو `VERCEL_OIDC_TOKEN` على Vercel. لا يختار الكود نموذجًا خفيًا. استُخدمت واجهة HTTP المتوافقة الموثقة لأن شبكة npm المحلية لم تستطع تنزيل AI SDK (`ENOTFOUND`). لا تبعية AI SDK غير مثبتة في المصدر. حد إخراج12000 token ومهلة150 ثانية، ومهمة تحليل نشطة واحدة لكل مشروع. تسجل رموز الاستخدام الفعلية؛ التكلفة تعرض فقط إن أعادها المزود، وإلا غير متاحة. لا تفترض أن مصادقة OIDC تثبت توفر رصيد. الخطأ في الرصيد أو إعداد النموذج يحجب المهمة مع السبب دون توليد نتائج بديلة مزيفة.

## الجودة والأولوية
تغطية الموضوع = عدد بنود مصفوفة التغطية المرتبطة بصفحة لوسيل ÷ عدد البنود؛ مقام هذه الدرجة تقدير نموذجي داخل العينة، لا عامل ترتيب. تغطية الأدلة = الادعاءات المعتمدة بشريًا ÷ الادعاءات؛ يبدأ البسط بصفر. اكتمال الاستخراج = المصادر غير الجزئية ÷ المصادر المستخدمة. المقام صفر يعني غير متاح، لا100%. الأوزان المقترحة20/25/20/15/10/10 موثقة، لكن لا درجة مركبة حتى يوجد تقييم بشري للدقة والأصالة والفائدة والتجربة والحداثة. الدرجة لا ترفع حاجز اعتماد النشر. الأولوية من1 أعلى إلى5 أقل، وهي تقدير تحريري معلل لا حجم بحث مقاس.

## الواجهات
- `GET /api/admin/intelligence?project=UUID&page=0`: المشاريع ومجموعات بيانات المشروع، مع تقارير البحث الأصلية وحدود القدرات.
- `POST /api/admin/intelligence`: union أفعال مضبوط في Zod: create_project/import_urls/queue/run/analyze/cancel/decide. الطلب يتطلب Origin مطابقًا ومديرًا فعليًا.
- `POST /api/admin/intelligence/import`: ملف multipart باسمfile، يحوله إلى قائمة روابط للمراجعة قبل حفظها.
- `GET /api/intelligence/worker`: Bearer CRON_SECRET فقط؛ يجدول المصادر المستحقة وينفذ مهمتين كحد أقصى. الجدول اليومي03:27 UTC، وليس كل8 ساعات. يمكن تنفيذ المهام يدويًا من اللوحة عند الحاجة. قيود Vercel الحالية لم تُستبدل بخدمة عمال منفصلة.

المصادر المضافة لها موعد إعادة فحص بعد7 أيام؛ الجدولة محدودة10 مصادر في التشغيل و100 في اليوم. التحليل الدلالي لا يتكرر تلقائيًا بتكلفة عند كل جلب؛ يطلبه المدير بعد مراجعة التغييرات. البصمات تمنع تكرار اللقطة المتطابقة، والرفض لا يعاد إحياؤه تلقائيًا لنفس النية.

## التشغيل والاختبارات
`npm run intelligence:test` يشغّل اختبارات الاستخراج وSSRF وrobots وXLSX وRLS والحجز والاستعادة وإلغاء المهام والاعتماد والمراجع. يتبعه lint وTypeScript وSEO QA وبناء Vercel واختبار المتصفح للمسار كاملًا. بيانات الاختبار الاصطناعية تبقى داخل الاختبارات، وأي مثال حي يذكر مصادره ونطاقه.

هجرة الإنتاج: `database/migrations/20261103151713_topic_intelligence_research_engine.sql`. لا تشغّلها مرتين؛ راجع سجل Supabase. نسخة bootstrap مطابقة في `database/intelligence-schema.sql`. للتراجع عطّل cron وأزل وصلة الواجهة أولًا؛ احتفظ بالبيانات ولا تنفذ DROP على أدلة حية. النسخ الاحتياطي وسياسة حذف المصادر المحتفظ بها تحتاج قرارًا إداريًا؛ السجلات محفوظة ولا يوجد حذف آلي دائم للأدلة في هذا الإصدار.

تشغيل وكلاء مستقلة في طابور موزع أوسع، وصلاحيات متعددة المستخدمين، وتحرير الخريطة والمقترحات مع إصداراتها، وربط الموافقات بمهام CMS وتعيينها، والتحقق البشري التفصيلي لكل ادعاء، وقواعد تمنع اعتماد نشر حساس، واحتساب الأوزان كاملة بعد تقييم بشري، واستكشاف نطاق موقع مصرح به، وإشعارات التغير والتعارض، وربط GSC API الحي ونتائج المستخدم، وتوليد ملفات فعلية من مواصفات الأدوات والمستندات، وسياسة الاحتفاظ والأرشفة، وجدولة أسرع حسب خطة الاستضافة. هذه ليست وظائف مكتملة في الإصدار الأول. لا وعد بترتيب أو فهرسة.
