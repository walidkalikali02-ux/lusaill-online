# دفعة صور المقالات — الجوازات وحماية المستهلك

التاريخ: 2026-11-11

## نطاق الدفعة
هذه الدفعة تعيد توجيه **صورة الغلاف الرئيسية بصيغة PNG** لعشرة مقالات منشورة إلى تصميم تحريري موضوعي مخصص داخل مولد صور لوسيل، مع الحفاظ على الصورة الأصلية للمقال كمكوّن بصري حيث تكون متاحة، وعدم العبث بمعلومات خطوات المقال أو تواريخ مراجعة المصادر.

| المقال | رمز التصور البصري | شارات الغلاف |
|---|---|---|
| passport-first-time-egypt | جواز | الهوية، المستندات، الطلب، الاستلام |
| passport-renewal-expired-full | تجديد | السبب، الجواز السابق، البيانات، الاستلام |
| passport-lost-inside-egypt | فقد | الإبلاغ، الهوية، البدل، المتابعة |
| passport-damaged-replacement-egypt | تلف | فحص التلف، الأصل، البدل، المراجعة |
| child-passport-egypt | جواز طفل | الميلاد، ولي الأمر، الصور، بيانات الطفل |
| passport-data-certificate-egypt | مستند | الغرض، الجواز، الطلب، فحص الشهادة |
| movement-certificate-egypt | تحركات | الفترة، مكان التقديم، الصفة، الاستلام |
| passport-urgent-service-egypt | وقت | الخدمة، المكان، الرسوم الرسمية، الاستلام |
| consumer-protection-complaint-egypt | شكوى | طلب الحل، التوثيق، الشكوى، المتابعة |
| consumer-return-exchange-egypt | استبدال | الشروط، الشراء، الإجراء، النتيجة |

**تنفيذ الموقع:** `lib/next-ten-cover-directions.ts` يعرّف البطاقات، و`lib/editorial-image-response.tsx` يصدر صورة PNG 1200×630 بخلفية موضوعية، ومرئيات المقال الأصلي، وشارة ذات رمز مخصص، وأربع بطاقات تلخيصية مستمدة من مسار المقال. روابط الأغلفة محدثة بإصدار لمنع استمرار CDN في عرض الملفات القديمة.

## حدود العمل
- هذه صور تحريرية تركيبية تُولَّد في الموقع، وليست صورًا فوتوغرافية جديدة مصدرها جلسة توليد صور خارجية.
- لا تُستخدم الرسوم الرسمية أو الأختام والخطابات المولّدة بوصفها وثائق حقيقية.
- لا تغيّر الصورة شروط إصدار الجواز أو الأسعار؛ يجب الرجوع إلى نص المقال والمراجع الحكومية الأحدث.
- الصور الموجودة داخل المقال محفوظة دون حذف. التحقق الفردي من أي صورة خارجية جديدة يبقى ضروريًا.

## اختبارات القبول
- تحصل المقالات العشرة على PNG HTTP 200 من `/api/editorial-image/articles/{slug}/cover?v=20261111-2`.
- صورة الغلاف نفسها تظهر على الصفحة، بطاقة المقال، وOpen Graph.
- لا توجد صور مشتركة لكل المقالات دون اختلاف موضوعي.
- الحروف العربية والأسماء والبطاقات غير مقصوصة.
- بقية المقالات تحتفظ بمسار الأغلفة الحالي ولا تتأثر بإضافات هذه الدفعة.
