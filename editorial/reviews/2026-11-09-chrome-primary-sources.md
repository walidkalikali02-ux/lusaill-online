## حدود اليقين
1. خطوات الواجهات مستندة إلى تعليمات Google على الكمبيوتر، ولا تعني أننا فتحنا إعدادات Chrome من جهاز مستخدم أو اختبرنا ملفات إشارات فعلية.
2. إعادة الضبط لا تحذف الإشارات وكلمات المرور حسب Google، لكن قد تتغير الأذونات والإضافات وبيانات المواقع. لا تساوي ذلك بفقد أو حفظ كل البيانات المحلية.
3. تصدير HTML للإشارات لا ينقل كلمات المرور والجلسات؛ حفظ بيانات Chrome في حساب Google مسار مختلف.
4. ملف Chrome الشخصي يساعد على التنظيم، لكنه ليس حاجزًا أمنيًا قويًا بين مستخدمي الجهاز، ووضع الضيف لا يخفي كل النشاط عن الشبكة.
5. تواريخ المصدر هنا تاريخ المراجعة التحريرية للوثائق، وليست شهادة باختبار كل خطوة في إصدار Chrome محدد.

## التحقق البرمجي
- `npm run editorial:qa`: يتحقق من 1000 كلمة فعلية أو أكثر في التوسعة و7 فصول ومراجع واضحة وعدم وجود صور ناقصة أو فقرات فارغة.
- `npm run seo:paths`: يختبر أهلية الفهرسة ومطابقة فصول الأدلة لمراجعها، ودخول عناوينها في خريطة الموقع فقط عند استيفاء قواعد التحرير.
- `scripts/editorial-inventory.mjs`: يسجل إجمالي المقالات ضعيفة التوثيق مع قائمة أولويات قابلة لإعادة الفحص. التقرير ليس بديلًا عن تدقيق صحة كل ادعاء.

## متابعة
بعد النشر، راجع الانطباع العام على الهاتف وأرشفة المراجع ورصد التغييرات في أسماء قوائم Chrome وإيضاحها داخل مقالات لوسيل. لا تكتف بزيادة كلمات النص لتبرير إلغاء noindex.
