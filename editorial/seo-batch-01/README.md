## بوابات الجودة
- قبل النشر: مراجعة واقعية للمصادر وحقوق الصورة، دقة الإحصاءات، وتجربة الجوال.
- الصحة/القانون/المال: مراجعة مختص إجبارية، ولا يُستخدم تخمين تاريخ المراجعة أو المؤلف.
- لكل صفحة عامة: جواب مباشر، قيمة أصلية قابلة للاختبار، مصادر مع اسم الجهة، canonical واحد، عنوان ووصف فريدان، عناصر بصرية موصوفة، وربط داخلي دلالي.
- تحديث سجل الإنتاج بعد كل اعتماد، ولا توسم صفحة بأنها منشورة قبل نشرها فعليًا والتحقق منها.
