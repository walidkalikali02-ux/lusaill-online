# مشروع تعميق موسوعة لوسيل — سياسة العمل

## النطاق الحالي
- مقال `chrome-update-check`: توسعة عربية أصلية تزيد على 1,000 كلمة، 9 فصول، رسم قرار، مراجع Google.
- مقال `tax-registration-reactivation`: توسعة عربية أصلية تزيد على 1,000 كلمة، 9 فصول، رسم قرار، مراجع مصلحة الضرائب (الإصدار الثاني 2025).
- التمييز بين تسعة أنواع من القوالب التحريرية أصبح على مستوى صفحة `/articles/[slug]`، وهو تغيير في ترتيب عناوين الأقسام والهوية المرئية وليس ادعاءً بتحويل بقية المقالات إلى 1,000 كلمة.
- المقالات الأخرى في /articles، والأقسام المستقلة /knowledge و/food-safety، **لم تُعد كتابتها بعد**. لا تضف نصوصًا آلية لمجرد تجاوز حد الكلمات.

## قاعدة تحريرية للأبحاث التالية
1. اقرأ المقال الحالي، ثم عرف الجمهور ومشكلته والنية الأساسية والنيات المساعدة.
2. اقرأ المصادر الأولية الرسمية أو الدراسات الأصلية وأي نقد علمي مناسب، واحفظ روابط الادعاءات وتواريخ الفحص. لا تنسب مراجعة لم تحدث.
3. اكتب فصولًا خاصة بالموضوع، لا «أهمية الموضوع» مكررة ولا إعادة صياغة نفس الخطوة.
4. أضف 1,000 كلمة فعلية على الأقل بحسب طلب مالك المشروع، لكن لا تنشر فقرة غير مفيدة فقط لإكمال العدد. لا يعامل Google حد 1,000 كلمة كمتطلب للفهرسة.
5. قدّم مثال قرار أو قائمة عملية أو مخطط أصلي إذا كانت تخدم المشكلة. لا توهم المستخدم بلقطة شاشة رسمية أو اختبار على جهاز لم يحدث.
6. حدّد الاستثناءات والمشاكل والرفض والتصعيد والتحقق النهائي. لا تعمم أحكامًا قانونية أو طبية.
7. راجع كل رابط وبيان قانوني حساس، وحدث `updatedAt` عند تعديل مادة حقيقي فقط.
8. طبّق `npm run editorial:qa` و`npm run lint` و`npm run build` قبل دمج محتوى جديد.

## مسارات استكمال التغطية
- الخدمات الحكومية: أهلية، مستندات، رسوم مثبتة، خطوات، حالات الرفض، المواعيد، القنوات.
- الكهرباء: شركة التوزيع، بيانات الحساب، الفاتورة والقراءة، السداد والأخطاء والاعتراض.
- مرور: أنواع الرخص، شروط كل نوع، الفحوص، المستندات، الاختبارات والاعتراضات.
- حقوق مستهلك: الواقعة والأدلة القانونية، التوثيق، الجهة والإجراء، المتابعة.
- العقود: النطاق، الأطراف والبنود، الفروق بين الحالات، مخاطر الصياغة.
- تقني: اختلاف النظام والنسخة، إعادة إنتاج المشكلة، الحل الآمن، التحقق والرجوع.
- محتوى صحي وعلمي: تعريف وشرح آلية وتأثير، الأدلة وحدودها، السلامة والاستشهاد ومراجعة مختص حين يلزم.

## النشر
لا تستبدل المحتوى القديم بمحتوى قالب فارغ. حافظ على الرابط الدائم والتاريخ الحقيقي ومحتوى القراءة والروابط. عدم ظهور الموقع في نتائج البحث لا يثبت أن المشكلة طول المقال وحده؛ راجع Search Console وتقارير الزحف منفصلة.
