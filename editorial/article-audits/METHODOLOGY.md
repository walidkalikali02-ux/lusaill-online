# منهجية توثيق المقالات

تاريخ التدقيق 2026-11-06. فهرس النطاق: https://www.lusaill.online/articles. تم إنشاء ملف مستقل لكل مقال منشور في الفهرس.

## مستويات الثقة

1. شاهدنا النص المرئي للصفحة: H1/H2/H3 والجداول والروابط الظاهرة وFAQ وموعد آخر تحقق من المصدر.
2. تحققنا من وجود آليات metadata وrobots وcanonical وOpen Graph وArticle/BreadcrumbList في كود الصفحة المشترك للموقع. هذا لا يحسم مخرجات HTML في الإنتاج.
3. الكلمات المقترحة والـOutline والنية والمكونات البصرية توصيات، وليست بحث كلمات مفتاحية من Search Console.
4. لم نفحص صحة جميع التصريحات الحكومية/الفنية بالمواقع الخارجية ولم نقس أداء Lighthouse أو GSC أو HTTP لكل رابط.

## معنى P0 وP1 وP2

P0 = صفر مصادر مرصودة؛ يلزم التأكد أن المشكلة ليست تعذر استخراج الصفحة. P1 = مضى 30 يومًا على التحقق الظاهر أو خطوات الإجراء H3 غير موجودة. P2 = بقية الملفات، وتظل مراجعة الحقائق والاختبارات التقنية لازمة للجميع. الألوان/الدرجات ليست حكمًا على ترتيب Google.

## معايير قبول التدقيق الكامل

لكل ادعاء حساس: النص + URL مصدر أصلي + تاريخ السريان + تاريخ التحقق + جهة الاختصاص + المراجع الحقيقي + نتيجة المطابقة. ثم راجع Title وMeta وCanonical وRobots وschema وHTTP وsitemap وروابط الصور وalt وmobile layout وLCP/INP/CLS وفهرسة GSC. دون ذلك تظل الحالة pending.
